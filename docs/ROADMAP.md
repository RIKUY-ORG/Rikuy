## Executive Summary

Rikuy is an anonymous civic reporting platform built on Arbitrum Orbit (L3) that enables Bolivian citizens to report corruption and public infrastructure failures with **100% anonymity** and **zero blockchain knowledge required**.

This roadmap outlines the phased execution strategy from post-buildathon launch through product-market fit and commercial scaling. The timing is strategically aligned with Bolivia's **subnational elections on March 22, 2026**, creating a unique window of political demand for transparency infrastructure.

## Competitive Advantage

| Factor | Rikuy | Traditional Reporting |
| :--- | :--- | :--- |
| Anonymity | ZK-proven, mathematically guaranteed | Requires identification |
| Evidence integrity | Immutable on blockchain + IPFS | Centralized servers, can be deleted |
| Sybil resistance | 1 citizen = 1 verified identity | No verification |
| Cost to citizen | Zero (gasless) | Physical presence, paperwork |
| Data accessibility | Real-time dashboards for institutions | Months-long FOIA requests |
| Censorship resistance | Decentralized L3 chain | Government-controlled |

## Risk Mitigation

| Risk | Mitigation |
| :--- | :--- |
| Low citizen adoption | $200 targeted ad campaign + civic org partnerships in 4 key cities |
| Government resistance to transparency | Position as a tool FOR governments to demonstrate accountability |
| Regulatory uncertainty | Compliance with *Ley 974* and existing anti-corruption frameworks |
| Technical infrastructure costs | Arbitrum Orbit L3 provides sub-cent transaction costs; VPS runs at ~$20/mo |
| Reclaim Protocol dependency | Modular architecture allows swapping identity providers if needed |
